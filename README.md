# AI-Based Restaurant Demand Forecasting and Real-Time Food Waste Management System

## 📌 Project Overview
This project is a web-based application designed to address demand uncertainty and food waste in restaurants. It combines machine learning regression models, real-time order monitoring, inventory tracking, and surplus food coordination.

## 🏗️ System Architecture / Layers
1. **Layer 1:** Input Sources (Historical sales, menu prices, dates, special events)
2. **Layer 2:** Frontend (HTML, CSS, JavaScript Dashboard & Order Entry Interface)
3. **Layer 3:** Backend Application (Python Flask)
4. **Layer 4A:** Machine Learning Module (Python, pandas, scikit-learn)
5. **Layer 4B:** Database Module (MySQL)
6. **Layer 5:** System Outputs (Demand predictions, prep quantities, alerts, waste reports)
